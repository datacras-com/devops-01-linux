MobaXterm Nədir?

MobaXterm — Windows üçün güclü SSH terminal proqramıdır. PuTTY-dən fərqli olaraq daxili SFTP fayl meneceri, X11 display server və çoxlu tab dəstəyi var.

MobaXterm Yüklə

  1. Brauzerdə aç: mobaxterm.mobatek.net/download.html
  2. Home Edition altında "Download now" düyməsini bas
  3. "MobaXterm Home Edition (Portable edition)" seç — ZIP fayl yüklənəcək
  4. ZIP faylı çıxart (sağ klik → "Extract All")
  5. MobaXterm_Personal_XX.X.exe faylına iki dəfə klik et — açıldı ✓
2

Ubuntu VM-də SSH Aktivləşdir

⚠️ Bu addım VirtualBox Ubuntu VM üçündür. Ubuntu-da terminal aç (Ctrl+Alt+T).
  1. SSH server qur:
bash — Ubuntu VM
sudo apt update
sudo apt install -y openssh-server
sudo systemctl enable ssh
sudo systemctl start ssh
  1. SSH işlədiyini yoxla:
bash
sudo systemctl status ssh
✓ "active (running)" yazısını görməlisən.
  1. Ubuntu-nun IP ünvanını öyrən:
bash
ip addr show | grep "inet " | grep -v "127.0.0.1"

Nəticə belə görünəcək: inet 10.0.2.15/24 — bu IP-ni qeyd et.

3

VirtualBox Network Ayarları

Windows (MobaXterm) ──SSH──► localhost:2222 ──► Ubuntu VM:22
  1. VirtualBox → VM üzərinə sağ klik → Settings
  2. Network → Adapter 1 → Attached to: NAT
  3. "Advanced" → "Port Forwarding" düyməsinə bas
  4. "+" ilə yeni qayda əlavə et:
NameProtocolHost IPHost PortGuest IPGuest Port
ssh TCP 127.0.0.1 2222 22
  1. OK → OK — VM-i restart etmə, dərhal işləyir
💡 MobaXterm-də Host: 127.0.0.1, Port: 2222 istifadə edəcəksən.
Windows (MobaXterm) ──SSH──► 192.168.56.x:22 ──► Ubuntu VM
  1. VirtualBox → File → Host Network Manager → mövcud vboxnet0 olduğuna əmin ol
  2. VM Settings → Network → Adapter 2 → Enable → Attached to: Host-only Adapter → vboxnet0
  3. VM-i yenidən başlat, Ubuntu-da ip addr ilə 192.168.56.x IP-ni tap
  4. MobaXterm-də bu IP-ni Host kimi istifadə et, Port: 22
4

MobaXterm ilə Qoşul

  1. MobaXterm-i aç → yuxarıda "Session" düyməsini bas
  2. Session tipi: "SSH" seç
  3. Remote host: 127.0.0.1 (NAT istifadə edirsənsə) və ya Ubuntu-nun IP-si
  4. "Specify username" ✅ qeyd et → student yaz
  5. Port: 2222 (NAT) və ya 22 (Host-only)
  6. "OK" → şifrə soruşarsa: student123
✓ Terminalda student@ubuntu-lab:~$ görünsə — bağlantı uğurludur!
5

  2. MobaXterm → Session → SSH
  3. Remote host: EC2-nin public IP-si
  4. "Specify username" ✅ → username:

VirtualBox Ubuntu VM-ə Qoşulmaq

Əvvəlcə Ubuntu VM-də SSH server qurulmuş olmalıdır (bax: Windows bölməsi, Addım 2). VirtualBox-da NAT + Port Forwarding ayarla (bax: Addım 3).

  1. Mac-da Terminal aç (Cmd+Space → "Terminal")
  2. Qoşul:
bash — Mac Terminal
ssh student@127.0.0.1 -p 2222
  1. İlk dəfə "Are you sure you want to continue connecting?" soruşarsa → yes yaz
  2. Şifrə: student123
✓ student@ubuntu-lab:~$ görünsə — bağlandın!
2

AWS EC2-yə Qoşulmaq

  1. .pem faylının icazəsini düzəlt:
bash
chmod 400 ~/Downloads/my-keypair.pem
  1. Qoşul (RHEL/Amazon Linux üçün):
bash
ssh -i ~/Downloads/my-keypair.pem ec2-user@<PUBLIC_IP>
  1. Ubuntu EC2 üçün:
bash
ssh -i ~/Downloads/my-keypair.pem ubuntu@<PUBLIC_IP>

Tez-tez Verilən Suallar

MobaXterm açılmır, "Windows protected your PC" çıxır
"More info" → "Run anyway" bas. Bu Windows SmartScreen xəbərdarlığıdır, normal haldır.
"Connection refused" xətası
Ubuntu VM-də SSH işləyirmi yoxla: sudo systemctl status ssh
Port Forwarding düzgün tənzimlənibmi? Host Port: 2222, Guest Port: 22
Ubuntu VM işləyirmi?
"Connection timed out" xətası
IP ünvanı düzgündür? NAT istifadə edirsənsə Host: 127.0.0.1, Port: 2222 olmalıdır.
Ubuntu-nun firewall-ını yoxla: sudo ufw status — əgər aktivdirsə: sudo ufw allow ssh
Şifrə düzgündür amma "Permission denied" çıxır
Username düzgündür? VirtualBox Ubuntu üçün: student
SSH server şifrə ilə girişə icazə verir? Ubuntu-da: sudo nano /etc/ssh/sshd_config → PasswordAuthentication yes olmalıdır → sudo systemctl restart ssh
MobaXterm sol tərəfində fayl meneceri açılmır
Bağlandıqdan sonra sol paneldə SFTP fayl meneceri avtomatik açılır. Görmürsənsə sol tərəfdəki kiçik oxu (◄) bas.
Mac-da "WARNING: UNPROTECTED PRIVATE KEY FILE!" xətası
.pem faylının icazəsini düzəlt:
bash
chmod 400 ~/Downloads/my-keypair.pem
