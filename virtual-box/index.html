VirtualBox Yüklə & Qur

⚠️ Apple Silicon üçün VirtualBox 7.1+ versiyası lazımdır. Köhnə versiyalar işləmir.
  1. virtualbox.org/wiki/Downloads səhifəsinə get
  2. "macOS / Apple Silicon hosts" seçimini yüklə — fayl adı: VirtualBox-7.x.x-macOS-arm64.dmg
  3. DMG-ni aç → VirtualBox.pkg-ni işə sal → "Continue" → "Install"
  4. System Settings → Privacy & Security → aşağıda "System Extension" bloku görünəcək → "Allow" bas
  5. Mac-ı restart et
  1. virtualbox.org/wiki/Downloads səhifəsinə get
  2. "macOS / Intel hosts" seçimini yüklə — fayl adı: VirtualBox-7.x.x-macOS-x86.dmg
  3. DMG-ni aç → VirtualBox.pkg-ni işə sal → "Continue" → "Install"
  4. System Preferences → Security & Privacy → "Allow" bas
  5. Restart tövsiyə edilir
  1. virtualbox.org/wiki/Downloads səhifəsinə get
  2. "Windows hosts" seçimini yüklə — fayl adı: VirtualBox-7.x.x-Win.exe
  3. .exe-ni işə sal → "Next" → "Next" → "Install"
  4. UAC xəbərdarlığı çıxarsa "Yes" de
  5. "Network Interface" soruşarsa "Yes" de — internet müvəqqəti kəsilə bilər

Ubuntu 24.04 ISO Yüklə

⚠️ Apple Silicon Mac-da ARM64 ISO lazımdır. Adi amd64.iso işləməz!

ARM64 ISO — cdimage.ubuntu.com

  1. cdimage.ubuntu.com/releases/24.04/release/ səhifəsinə get
  2. Fayl adı: ubuntu-24.04.4-desktop-arm64.iso (~3.3 GB)
  3. Yükləmə ~10-20 dəq çəkə bilər — əvvəlcədən yüklə

AMD64 ISO — ubuntu.com/download/desktop

  1. ubuntu.com/download/desktop səhifəsinə get
  2. Fayl adı: ubuntu-24.04.x-desktop-amd64.iso (~6 GB)
  3. Yükləmə ~10-20 dəq çəkə bilər — əvvəlcədən yüklə

  1. VirtualBox-u aç → "New" düyməsini bas
  2. Name: Ubuntu-24.04 | ISO Image: yüklədiyin .iso faylını seç | "Skip Unattended Installation" ✅ qeyd et
  3. Hardware: Base Memory → 4096 MB, Processors → 2
  4. Hard Disk: "Create a Virtual Hard Disk Now" → 25 GB
  5. "Finish" — VM yarandı

Ubuntu Qur

  1. VM-i seç → "Start" düyməsini bas
  2. Boot menüsü → "Try or Install Ubuntu"
  3. Dil seç → "Install Ubuntu"
  4. Keyboard: English (US)
  5. "Normal Installation" seç
  6. "Erase disk and install Ubuntu" → "Install Now" → "Continue"
  7. Timezone: Baku
  8. İstifadəçi: Name: Student | Username: student | Password: student123
  9. "Install" → ~10-15 dəqiqə gözlə
  10. "Restart Now" → Enter — Ubuntu hazırdır ✓

Quraşdırmadan Sonra

Ubuntu-da terminal aç (Ctrl+Alt+T) və bu paketləri qur:

bash 
sudo apt update && sudo apt upgrade -y
sudo apt install -y \
  curl wget git vim nano \
  net-tools iputils-ping \
  python3 python3-pip \
  docker.io docker-compose \
  htop tree unzip
💡 Shared Clipboard (Mac ↔ Ubuntu kopyala-yapışdır): VM Settings → General → Advanced → Shared Clipboard: Bidirectional
💡 Tam ekran: VM işləyərkən Host+F (Mac-da: Left Cmd+F)

Tez-tez Verilən Suallar

VM çox yavaşdır, nə edim?
Settings → System → Processor → Enable PAE/NX aktivləşdir.
Settings → Display → Video Memory-ni 128 MB et.
2-dən çox CPU core ver.
Apple Silicon-da "Kernel driver not installed" xətası
System Settings → Privacy & Security → "Allow" düyməsi görünməlidi.
Görmürsənsə terminaldə işlət:
bash
sudo /sbin/vboxconfig
"VERR_NEM_VM_CREATE_FAILED" xətası (Apple Silicon)
VirtualBox versiyası 7.1-dən aşağıdır. Yenilə:
virtualbox.org/wiki/Downloads → macOS Apple Silicon
VM-i tam silmək istəyirəm
VirtualBox-da VM üzərinə sağ klik → "Remove" → "Delete all files"
Ubuntu-da internet işləmir
VM Settings → Network → Adapter 1 → Attached to: NAT seç → OK → VM-i restart et.
