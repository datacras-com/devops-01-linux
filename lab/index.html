Dərsin praktikasını skript sizin əvəzinizə izah edir. Siz izləyir, proqnoz verir və tapşırığı özünüz həll edirsiniz.

Başlamaq (Ubuntu VM-də)

git clone https://github.com/datacras-com/devops-01-linux.git
cd devops-01-linux/lab
./run list          # bütün dərslər
./run 03            # Sessiya 03-ü addım-addım keç
Öz VM-nizdə işlədin, iş serverində yox. Hər şey ~/devops-lab/ sandbox-ında baş verir. Sistemi dəyişən dərslər (istifadəçi, paket) bitəndə özü geri qaytarır.
